# Coverage and meaning

Catalogue verification:25 body families, 4,849 searchable entries:92 organs,169 original curated condition examples,12 investigations,4,484 attributed existing atlas terms and92 existing analytes. This is progressive whole-body navigation and evidence organization, not a complete medical terminology release or universal diagnostic model.

All requested families are present: neurological, cardiac/coronary, respiratory, hepatobiliary, urinary, pancreas, digestive, skeletal, muscle/connective, endocrine, blood/bone marrow, immune/lymphatic, skin, eye, ENT, oral/dental, breast, female reproductive, male reproductive, maternal/foetal/neonatal, peripheral/systemic vessels, infectious, genetic/metabolic/rare, mental/neurodevelopmental and systemic/multisystem.

The importer and schema retain source/version/rights, synonyms, parent relations, laterality when provided, typed evidence associations and explicit unverified mappings. Existing atlas terms are reference structures with attribution, not newly segmented patients or newly generated3D assets. Existing dedicated atlas assets remain available only where the source asset actually exists. A family without a dedicated mesh/model remains navigable with an explicit unavailable state.

Condition entries remain `CATALOGUE_ONLY` even if they have an exact candidate model-target association. Model support is a separate runtime gate over actual registry status, rights, files/checkpoint hashes, target/input contract and evaluation. No catalogue label upgrades clinical eligibility. Mental/systemic/genetic records do not require or imply a visible lesion.

Official exhaustive ICD/SNOMED disease mapping was not supplied or invented. New condition code mappings are empty. Existing analyte LOINC associations remain marked RELATED/CURATED_UNVERIFIED where applicable; they are not promoted to verified standards equivalence.

Exact counts, per-family terms, source hashes and current candidate preflight states are in `catalogue-verification.json`. Eighteen exact linked model/target entries were checked:15 research preflights available and3 blocked. These counts are not the count of models actually executed in this session or of clinically validated diseases.
